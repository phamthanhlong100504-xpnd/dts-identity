---------------------------------------------------------------

Ngôn ngữ + technical 

API Gateway: Spring Cloud Gateway
Backend Framework: Java Spring Boot
Frontend Framework: React.js
Cơ sở dữ liệu chính: PostgreSQL : Lưu db thêm sửa xóa.
Lưu log : ClickHouse ( audit_log + outbox ) 
Cơ sở dữ liệu bộ nhớ đệm (Caching): Redis
Message Broker (Giao tiếp bất đồng bộ): Apache Kafka
Container hóa & Triển khai: Docker và Kubernetes
