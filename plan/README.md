# Implementation Plans

Thư mục này lưu trữ các kế hoạch triển khai đã được phê duyệt (approved plans).

## Quy tắc

- File đặt tên theo format: `DD-MM-YYYY-HH-mm-<mô-tả-ngắn>.md`
- Mô tả ngắn bằng tiếng Việt không dấu, phân cách bằng dấu gạch ngang
- **Không xóa plan cũ** — luôn giữ lại lịch sử
- Mỗi plan được lưu ngay sau khi được phê duyệt
